# Supplementary visual references

This directory stores the latest working visual references and figure drafts
kept with the experiment handoff. The canonical figures used by the anonymous
paper are under `paper/figures/` and the editable figure packages are under
`paper/figure2_bestpaper/`, `paper/figure3_bestpaper/`, and
`paper/figure4_lm_validation/`.

The images here are reference assets; they do not introduce additional
quantitative claims beyond the checked-in paper and data artifacts.
